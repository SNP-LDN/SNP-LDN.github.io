Wallpaper Box is a lightweight Windows desktop application for managing local Wallpaper Engine libraries without uploading wallpaper files or requiring Wallpaper Engine to remain open. It scans folders for image and animated GIF previews, then provides search, sorting, source filters, adjustable layouts, favorites, collections, and bulk selection.

The app can check Steam Workshop availability, retrieve official wallpaper titles, and associate wallpapers with programs or media files for quick launching. It provides Chinese and English interfaces, stores user settings locally, and supports installer and portable builds with update checking.

**Technologies:** JavaScript, Electron, Node.js, HTML, CSS, electron-builder, electron-updater
