Better Clipboard is a Windows clipboard-history application built with C#, WPF, and .NET 9. It runs from the system tray and opens a searchable history window with `Ctrl+Alt+V`, supporting text, file paths, screenshots, and images.

The app includes favorites and custom folders, configurable retention, source-application tracking, light and dark themes, and automatic updates. Its privacy layer uses Windows DPAPI encryption, skips private browser windows and password managers, rejects common API keys and tokens, and masks temporary codes and payment-card-like values.

**Technologies:** C#, WPF, .NET 9, Windows APIs, DPAPI, Velopack
